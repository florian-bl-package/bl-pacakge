IBL_draw_plot

Description

A function which can be used to draw plots

Usage

IBL_draw_plot(plot = ggplot2::last_plot(), plot_width = NA,
  plot_ratio = NA, plot_rows = NA, plot_cols = NA,
  plot_distance_x = NA, plot_distance_y = NA, add_margins = T,
  align_plots = T, hight_adjust = NA, width_adjust = NA)

Arguments

plot

plot or list of plots to be drawn. Several plots MUST be put in a list.

plot_width

sets the with of each plot in the panel in mm. Is overwritten by "single_column" if existant, else defaults to 90 mm.

plot_ratio

sets the aspect ratio of each plot in the panel. Defaults to 1, but plots with fixed aspect ratio keep their aspect ratio if nothing is provided.

plot_rows

for multiple plotting sets the number of rows of the plot panel.

plot_cols

for multiple plotting sets the number of columns of the plot panel.

plot_distance_x

sets the distance between multiple plots in x direction.

plot_distance_y

sets the distance between multiple plots in y direction.

add_margins

if TRUE, margins are added to the panel width.

align_plots

if speciefied, multiple plots are aligned in the panel. Possible values: TRUE and "hv" align both horizontally and vertically. "h" aligns horizontally. "v" aligns vertically
