IBL_barplot_dat {IBL}R Documentation

IBL Barplot data table'

Description

IBL_barplot_dat takes a table of raw data and puts out a summary (mean and standard error) of a focal variable grouped by up to two grouping variables. The resulting table is especially useful for plotting barplots with ggplot2.

Usage

IBL_barplot_dat(input_frame = NA, focal_var = NA, group_var1 = NA,
  group_var2 = NA, order1 = NA, order2 = NA, error_bar = F)

Arguments

input_frame

A data frame containing the raw data to be plotted.

focal_var

The focal variable. Must be numeric. Can contain NAs, however, NAs always need a sensible approach.

group_var1

The first order groupng variable. Must be specified.

group_var2

Optional. A second order grouping variable.

order1

Optional. The order of the levels of group_var1

order2

Optional. The order of the levels of group_var2. Is ignored if group_var2 is not specified.

error_bar

Logical. Should error bars be computed?

Examples

#
morley
IBL_barplot_dat (input_frame = morley, focal_var = "Speed", group_var1 = "Expt")
#
#
#
mpg
IBL_barplot_dat (mpg, "cty", "drv", "class", error_bar = T, order1 = c ("f", "4", "r"))
#
#
#
library (tidyverse)
npk %>% IBL_barplot_dat ("yield", "N", "P", error_bar = T)

plot_dat <- IBL_barplot_dat (npk, "yield", "N", "P", error_bar = T)
ggplot (plot_dat, aes (x = N, y = yield, fill = P)) +
geom_bar (stat = "identity", position = "dodge", color = "black" ) +
geom_errorbar (aes (ymin = yield - SE_yield,
              ymax = yield + SE_yield),
              width = 0.3,
              position = position_dodge (.9)) +
scale_fill_manual (values = c (IBL_blue (1), IBL_blue (5))) +
IBL_y_scale (limits = c (0, 65), air = F) +
theme (legend.position = "none") +
IBL_theme ()
