IBL_save_svg {IBL}R Documentation

IBL Save Svg

Description

Saves a plot with embedded font to svg. Can either be the last plot that has been drawn or any plot stored as an object. See also Cairo::CairoSVG, as IBL_save_svg is based on it.

Usage

IBL_save_svg(plot = ggplot2::last_plot(), file_path = NA, width = NA,
  height = NA)

Arguments

plot

The plot to be saved. Defaults to the last plot created.

width

Width of the Plot Panel to be created. Can be supplied via panel_width. Otherwise, if 'plot' has a panel width argument, this is taken as width. Defaults to 90 mm.

file

The path of the file to be created.

heigth

heigth of the Plot Panel to be created. Can be supplied via panel_height. Defaults to 90 mm.

Examples

library (ggplot2)    ## Required for plotting.

my_plot <- ggplot (iris, aes (Sepal.Length, Sepal.Width, color = Species)) +
        geom_point () +
        IBL_theme ()

IBL_save_svg (my_plot)
