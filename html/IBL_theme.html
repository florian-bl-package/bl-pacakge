IBL_theme {IBL}R Documentation

IBL Theme

Description

A standard IBL Theme for plotting with ggplot2. 'IBL_theme' is a wrapper for 'ggplot2::theme'. It accepts all additional parameters of 'theme'.

Usage

IBL_theme(aspect.ratio = NA, panel.background = "blank", lsize = NA,
  axis.text.color = "black", axis.text.size = 14, text.size = 18,
  text.font = "ChantillyLH", label.text.color = "black",
  x.margin = 5, y.margin = 5, axis.title.x = NA, axis.title.y = NA,
  ...)

Arguments

aspect.ratio

The ratio of x and y axis. Is specified via plot_ratio; if plot_ratio is not given defaults to 1.

panel.background

Defaults to a blank background.

lsize

Defines the thickness of axes and major ticks. If given, is specified via line_size; else defaults to 0.3 mm.

axis.text.color

Sets the color of tick annotations.

axis.text.size

Sets the text size of tick annotations.

text.size

Sets the text size of the axis labels.

text.font

Globally sets the fornt for the plot.

label.text.color

Globally Sets the Text Color.

x.margin

sets the vertical margin around the plot. If not given defautls to 5. Interacts with y.margin. Particularly important for plotting several graphs on a page. Is overwritten by plot_distance_x.

y.margin

sets the horizontal margin around the plot. If not given defautls to 5. Interacts with x.margin. Particularly important for plotting several graphs on a page. Is overwritten by plot_distance_y.

...

all parameters accepted by 'ggplot2::theme()' can also be used with IBL_theme (). Some logical conflicts produce an error. In these cases, it is adviced to use 'theme()' seperately. For further assistance view '?theme'.

tick.length

Globally defines the length of the major ticks in mm. Defaults to 1.5.

Examples

library (ggplot2)    ## Required for plotting.
library (extrafont)  ## Required for the standard - IBL - font "ChantillyLH". ChantillyLH must be registered in R.

ggplot (iris, aes (Sepal.Length, Sepal.Width, color = Species)) +
        geom_point ()+
        IBL_theme (x.margin = 10)



########
## external control of plot ratio and line size

library (ggplot2)
library (extrafont)

plot_ratio <- 0.3
line_size <- 2

ggplot(iris, aes(Sepal.Length, Sepal.Width, color = Species)) +
       geom_point()+
       IBL_theme(x.margin = 10)

##
ggplot(iris, aes(Sepal.Length, Sepal.Width, color = Species)) +
       geom_point()+
       IBL_theme(x.margin = 10, aspect.ratio = 2, lsize = 0.1)   # aspect.ratio and lsize are not overwritten by plot_ratio and line_size


plot_distance_x <- 100

ggplot(iris, aes(Sepal.Length, Sepal.Width, color = Species)) +
       geom_point()+
       IBL_theme(x.margin = 10)                                  # x.margin and y.margin are overwritten by plot_distance_x and plot_distance_y
