IBL_signi {IBL}R Documentation

IBL significance codes

Description

IBL significance codes

Usage

IBL_signi(signi_codes = NA, bar = "ontop", distance = 0.4,
  font = "ChantillyLH", text_size = 5, ...)

Arguments

signi_codes

A character vector of length 1 or the number of groups displayed in the barplot. This is the text to be plotted above the bars

bar

"ontop" or "between". Shall the annotations be drawn on top of the (grouped) bars or between the bars / bar groups?

distance

A numeric vector of length 1 or the number of groups displayed in the barplot. Adjusting for different label types may be useful when different types of text shall be displayed (e.g. 0.9 for "n.s." and 0.1 for "*"). This is the distance of the text to the bars, or - if present - error bars.

font

A character vector of length 1 or the number of groups displayed in the barplot. Can be any font known to your R. Each label can have their own font (which is not advicably in most cases).

text_size

A numeric vector of length 1 or the number of groups displayed in the barplot. As fot the distance, can be adjusted for different types of text (e.g. 6 for "n.s." and 8 for "*").

Examples

## grouped barplot with error
plot_dat <- IBL_barplot_dat (npk, "yield", "N", "P", error_bar = T)

p <- ggplot (plot_dat, aes (x = group_N, y = yield, fill = subgrp_P)) +
geom_bar (stat = "identity", position = position_dodge2 (padding = 0.15), color = "black", width = 0.7 ) +
geom_errorbar (aes (ymin = yield - SE_yield,
              ymax = yield + SE_yield),
              width = 0.3,
              position = position_dodge (0.7)) +
scale_fill_manual (values = c (IBL_blue (5), IBL_blue (1))) +
IBL_y_scale (limits = c (0, 70), air = F) +
labs (x = "N", y = "Yield") +
IBL_theme (legend.position = "none")

p

p + IBL_signi(c ("n.s.", "*"), text_size = c (6,8), distance = c (0.9, 0.1))

p + IBL_signi ("**", bar = "between")
