IBL_y_scale {IBL}R Documentation

IBL scale

Description

Creates axis with customizable ticks. Minor ticks are possible.

Usage

IBL_x_scale (sides = "b",
               major_x = 5,
               minor_x = NA,
               major_ticklength = 1.5,
               minor_ticklength = 1,
               colour = "black",
               size = NA,
               limits = NULL,
               air = NA,
               ...)


IBL_y_scale (sides = "b",
               major_y = 5,
               minor_y = NA,
               major_ticklength = 1.5,
               minor_ticklength = 1,
               colour = "black",
               size = NA,
               limits = NULL,
               air = NA,
               ...)

Arguments

sides

One or a combination of the letters "b" (bottom), "l" (left), "t" (top), "r" (right)

major_ticklength

the length of the major ticks to be drawn, specified in mm.

minor_ticklength

the length of the minor ticks to be drawn, specified in mm.

colour

the colour of the ticks; color and colour are interchangeable

size

the thickness of the ticks

linetype

set the line type. most of the time, dashed lines won't make sense (but are possible)

alpha

set the transparency of the ticks (other than 1 seems not to be very useful)

scale

set the scale of the axis. "identity" should workl for 99 percent of the cases, but "log" or other scales are also possible.

scaled

logical. are the axis scaled? as with scale, don't mess with this parameter. in 99 percent of the cases, "TRUE" will do the job.

air

expands the plots over the actual plot limits.

limits

set the limits of the axis

major_x

the number of major ticks on the x axis. can be (i) a single number, based on which the breaks are calculated via scales::extended_breaks or (ii) a vector of points.

minor_x

the number of minor ticks on the x axis. handled in analogy to major_x.
