IBL_green {IBL}R Documentation

IBL Colors

Description

blue, green and red in different tints for usage in IBL plots.

Usage

IBL_blue (tint = 3)

IBL_green (tint = 3)

IBL_red (tint = 1)

Arguments

tint

An Integer between 1 and 5 which specifies the tint of the color. For IBL_red (), only "1" is possible.

Examples

## IBL_blue(3)
#
#
#
p <- ggplot(iris, aes(Sepal.Length, Sepal.Width)) +
            geom_point (color = IBL_blue (3))

p

p + geom_point (color = IBL_red ())
p + geom_abline (intercept = 0,
                 slope = .5,
                 color = IBL_green (3))
