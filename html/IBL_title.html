IBL Title

Description

Adds a title to the plot, by default inside the plotting region. This is particularely useful when creating several plots to be aligned within the same panel. Note that the function needs a ggplot2 - plot object as input. The workflow should thus be: i) create the plot and ii) add the titel afterwards.

Usage

IBL_title(plot = ggplot2::last_plot(), title = "plot title", x = 0.5,
  y = 0.97, xrel = T, yrel = T, font = "ChantillyLH",
  text_size = 5, align_lr = 0, align_tb = 1, ...)

Arguments

plot

the plot the title will be added to.

title

the title for the plot.

x

the x-position of the title. If the x-axis is a continuous scale and xrel is set to "TRUE", this is a relative position (e.g. at 50 percent of the x-axis). Otherwise, this is an absolute position (e.g. at x = .5).

y

the y-position of the title. If the y-axis is a continuous scale and yrel is set to "TRUE", this is a relative position (e.g. at 90 percent of the y-axis). Otherwise, this is an absolute position (e.g. at y = .9).

xrel

logical. relative or absolute x-position?

yrel

logical. relative or absolute y-position?

font

the font of the title

text_size

the text size of the title

...

additional arguments, for detail see '?geom_text'.
